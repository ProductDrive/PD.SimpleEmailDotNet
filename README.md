# PD.SimpleEmailDotNet
An outbound-only email services
## Features
* Authenticate your email credentials dynamically
* Send single email
* Send an email message to multiple receivers with or without cc and bcc
* Send many messages to single receiver
* Send unique messages to multiple recievers
* Send message using email templates designed for you.
